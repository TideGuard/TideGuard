Before you deploy

Eight steps from zero to production. Most settings live in /admin after deploy — not in Wrangler prompts.

Deploy

  1. 1

    Generate a secret

    Create TOKEN_SECRET — you will paste it twice: once at deploy, once when you claim /admin.

    Generate at tideguard.dev/token
  2. 2

    Deploy to Cloudflare

    Use Deploy to Cloudflare or Wrangler. Only TOKEN_SECRET is prompted — queue, origin, and Turnstile are set in /admin later.

    Deploy to Cloudflare
  3. 3

    Claim the control room

    Open /admin, paste TOKEN_SECRET, choose username + password, and save the 12-word recovery phrase (shown once).

    Getting started guide

Setup wizard

  1. 4

    Connect Cloudflare

    Paste API token → verify → zone & hostname → SSL → attach domain. All from TideGuard — not the dashboard.

    Admin guide
  2. 5

    Turnstile + queue

    Protect admin login with Turnstile. Pick queue mode and branding, then Finish.

    Admin guide

Go live

  1. 6

    Demo mode first

    Origin stays ungated. Smoke-test /demo and /wait?return=/demo in an incognito window.

    Protecting origin
  2. 7

    Go live

    Set origin URL and enable protect-all (or path prefixes). Unauthenticated traffic → waiting room; admitted → your site.

    Origin proxy
  3. 8

    Launch checklist

    Capacity, SSL, webhooks, schedules — walk the checklist before real traffic.
